# 3D 태양계 시뮬레이션

React와 Three.js를 사용하여 만든 인터랙티브 3D 태양계 시뮬레이션입니다.

## 주요 기능

- 태양계의 모든 행성 구현
- 행성들의 자전과 공전
- 목성의 갈릴레이 위성 (이오, 유로파, 가니메데, 칼리스토)
- 소행성대
- 혜성과 우주 먼지
- 행성 정보 툴팁
- 3D 카메라 컨트롤

## 사용 기술

- React
- Three.js (@react-three/fiber)
- @react-three/drei
- TypeScript

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm start
```

## 조작 방법

- 마우스 드래그: 카메라 회전
- 마우스 휠: 줌 인/아웃
- 행성 호버: 행성 정보 표시
